# Open Library Books

## Description

This Python script gets information about 50 books from the Open Library API.

It filters the books published from the year 2000 onwards, sorts them by publication year, and saves the results in a CSV file.

## Requirements

* Python
* requests

## Installation

Install the `requests` library:

```bash
pip install requests
```

## How to Run

Run the Python script:

```bash
python main.py
```

## Output

The program creates a file named:

```text
books.csv
```

The CSV file contains the following information:

* Title
* Author
* Publication Year

## API

This project uses the Open Library API.
